# Sintaxis Studio

**Análisis sintáctico, lógica y conjuntos para la enseñanza y el estudio del lenguaje.**

Sintaxis Studio es una aplicación para Windows que permite construir, revisar y representar análisis lingüísticos, preparar ejercicios y explorar relaciones lógicas y conjuntos. Su desarrollo se incorpora al proyecto CITE STEAM como herramienta para la reflexión sobre el lenguaje y la elaboración de materiales educativos.

**[Descargar la última versión](https://github.com/jesuspvsc-netizen/SintaxisStudio-Releases/releases/latest)** · [Consultar las publicaciones disponibles](https://github.com/jesuspvsc-netizen/SintaxisStudio-Releases/releases)

## Qué permite hacer

| Área | Funciones |
| --- | --- |
| Perfil docente | Análisis mediante rayas, árbol y paréntesis; edición de categorías y funciones; ejercicios con ocultaciones y respuestas; fichas de varias oraciones. |
| Gramática generativa | Editores de X-barra y Minimalismo, movimientos, índices, rasgos y secuencias de pasos. |
| Lógica de enunciados | Escritura de fórmulas, tablas de verdad y comprobación de argumentos. |
| Lógica de predicados | Estructura y ámbitos de cuantificación, evaluación y comparación en modelos finitos, testigos y contraejemplos. |
| Conjuntos | Operaciones y expresiones, diagramas de Venn, comparación en un modelo y comprobación de identidades generales. |
| Materiales | Guardado de documentos y salidas en texto editable, imágenes, HTML e impresión/PDF, según el editor. |

En lógica de predicados, la evaluación en un modelo finito no determina por sí sola la validez general. En conjuntos, la comprobación de identidades generales es independiente del modelo escrito en el editor.

## Instalación en Windows

1. Abre [la última versión](https://github.com/jesuspvsc-netizen/SintaxisStudio-Releases/releases/latest).
2. En **Assets**, descarga el archivo cuyo nombre comienza por **SintaxisStudio-Setup-** y termina en **-win-x64.exe**.
3. Cierra Sintaxis Studio si lo tienes abierto y ejecuta el instalador.
4. Abre la aplicación y consulta **Acerca de** para comprobar la versión instalada.

Requisitos: Windows 10 o Windows 11 de 64 bits. La aplicación es autocontenida: no hace falta instalar Visual Studio ni .NET por separado.

Los archivos que GitHub presenta como **Source code (zip)** y **Source code (tar.gz)** corresponden a la documentación de este repositorio; para instalar el programa descarga el **.exe**.
